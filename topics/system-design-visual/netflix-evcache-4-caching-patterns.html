Netflix EVCache — 4 Caching Patterns

How Netflix uses a distributed cache to keep playback inside the first 90 seconds.

2 min read · topic 5 of 5 in Caching

Netflix uses EVCache (distributed key-value store) to keep users streaming within the critical 90-second attention window:

  1. Lookaside Cache — check EVCache first; miss → backend + Cassandra → update cache
  2. Transient Data Store — playback session state across multiple services
  3. Primary Store — pre-computed home pages (nightly batch job writes, online services read)
  4. High-Volume Data — UI strings, translations; async compute + publish to EVCache
