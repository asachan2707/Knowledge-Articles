TCP vs UDP

Reliable ordered streams versus fast fire-and-forget datagrams, and where each is used.

2 min read · topic 4 of 8 in Networking
FeatureTCPUDP
ConnectionConnection-oriented (3-way handshake)Connectionless
ReliabilityGuaranteed delivery, orderedBest-effort, may lose packets
SpeedSlower (overhead)Faster (low overhead)
Use casesHTTP, HTTPS, email, file transferVideo streaming, DNS, gaming, IoT, VoIP

UDP top use cases: Live streaming / VoIP (tolerate packet loss, need low latency) · DNS (fast, single small query) · Market data multicast (deliver to many simultaneously) · IoT (small packets, constrained devices)
