API Pagination — 6 Techniques

Offset, cursor, keyset and four more ways to page results, and where offset breaks.

2 min read · topic 4 of 6 in APIs
TechniqueExampleBest for
Offset-based?offset=0&limit=10Simple lists, admin UIs
Cursor-based?cursor=abc123Social feeds, large datasets
Page-based?page=2&size=10Traditional paginated UIs
Keyset-based?after_id=1002&limit=10Consistent pagination, avoids drift
Time-based?start_time=T1&end_time=T2Time-series data, event logs
HybridCursor + time rangeComplex real-time feeds

Offset pagination pitfall: At large offsets, the database must scan and skip rows — O(N) cost. Cursor or keyset pagination is O(1) per page regardless of depth. Twitter and Facebook use cursor-based for their feeds.
