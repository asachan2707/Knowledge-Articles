top, vmstat, iostat, strace and friends: which tool shows what.

2 min read · topic 4 of 9 in Infrastructure
ToolWhat it shows
vmstatProcess, memory, paging, block I/O, CPU activity
iostatCPU and I/O stats per device
netstatIP, TCP, UDP, ICMP protocol stats, open connections
lsofAll open files (sockets are files in Linux)
pidstatPer-process CPU, memory, I/O, thread stats
top / htopLive process monitor; CPU/memory per process
perfKernel-level performance profiling, CPU cycles
