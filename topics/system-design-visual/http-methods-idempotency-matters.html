HTTP Methods — Idempotency Matters

GET, PUT, POST, DELETE and friends, and which ones are safe to retry.

2 min read · topic 2 of 8 in Networking
MethodActionIdempotentNotes
GETRetrieve resource✅ YesNever mutates state. Cacheable.
POSTCreate resource❌ NoDouble call = duplicate creation
PUTCreate or replace✅ YesFull replacement of resource
PATCHPartial update❌ UsuallyDepends on implementation
DELETERemove resource✅ YesSecond call returns 404, not error
HEADGET headers only✅ YesUseful for cache validation
OPTIONSAllowed methods✅ YesUsed in CORS preflight
