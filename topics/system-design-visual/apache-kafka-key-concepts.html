Apache Kafka — Key Concepts

Topics, partitions, consumer groups and offsets, and the three places Kafka can lose messages.

2 min read · topic 1 of 7 in Messaging

Can Kafka lose messages? Yes — if misconfigured. Three danger points: (1) Producer: must set acks=all and retries>0. (2) Broker: async disk flush means unacked messages lost on crash — configure replication factor ≥ 3 and min.insync.replicas=2. (3) Consumer: auto-commit can ack a message before it's processed — use synchronous commit in exception handlers.
