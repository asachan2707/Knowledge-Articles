Key Trade-offs in System Design

Cost vs performance, reliability vs scalability, performance vs consistency, security vs flexibility.

2 min read · topic 6 of 7 in Foundations

Cost vs Performance

More nodes, faster disks, CDN — each costs money. Establish the latency budget before over-provisioning.

Reliability vs Scalability

Strong consistency limits horizontal scale. Eventual consistency enables it.

Performance vs Consistency

Caching improves reads but introduces staleness. Decide your staleness tolerance first.

Security vs Flexibility

Tighter auth and encryption add latency. Mututal TLS (mTLS) between services is correct but costly.
