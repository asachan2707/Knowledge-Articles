The Fantastic Four: Scalability, Availability, Reliability, Performance

The four qualities every design is judged on, what each means, and the techniques that buy them.

2 min read · topic 1 of 7 in Foundations

🔼 Scalability

  • Handle more load without degrading performance
  • Horizontal: Add more servers
  • Vertical: Bigger machines
  • Stateless services scale horizontally easiest

🟢 Availability

  • System is up and serving requests
  • 4 nines = 99.99% = 8.64s downtime/day
  • Techniques: redundancy, failover, health checks
  • Hot-hot vs hot-warm vs single-leader cluster

✅ Reliability

  • Consistently delivers correct results
  • Tolerates hardware faults, software errors
  • Techniques: replication, checkpointing, retries

⚡ Performance

  • Carries tasks at expected rate under peak load
  • Metrics: QPS, TPS, p99 latency
  • Amazon: every 100ms latency = 1% lost sales
  • Techniques: caching, async, CDN, indexing
