Reverse Proxy vs API Gateway vs Load Balancer

Three front-door components that look alike, and what each is actually for.

2 min read · topic 2 of 8 in Architecture

🔀 Reverse Proxy

  • Fetches resources on behalf of client
  • Hides backend server identity
  • SSL termination, compression, caching
  • Use for: security, DDoS protection
  • e.g. Nginx, HAProxy

📬 API Gateway

  • Routes requests to correct microservices
  • Auth, rate limiting, request transformation
  • Protocol translation (REST → gRPC)
  • Use for: microservices entry point
  • e.g. Kong, AWS API Gateway, Zuul

⚖️ Load Balancer

  • Distributes traffic evenly across servers
  • Health checks, failover
  • 6 algorithms (see below)
  • Use for: scaling horizontally
  • e.g. AWS ALB/NLB, HAProxy
