What Happens When You Type a URL?

Step by step from the Enter key to a rendered page: DNS, TCP, TLS, HTTP and the server response.

2 min read · topic 1 of 8 in Networking

DNS resolution checks: browser cache → OS cache → local network cache → ISP cache → recursive DNS resolver. TCP uses a 3-way handshake (SYN → SYN-ACK → ACK). HTTPS adds a TLS handshake on top.
