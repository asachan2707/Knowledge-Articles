Stop Returning JSON: Start Shipping UI with MCP Apps

MCP Apps extends the Model Context Protocol to deliver interactive HTML/JS interfaces alongside tools — not Markdown narration, but actual rendered applications inside sandboxed iframes. One capability, two interfaces: the agent uses the tool, the human uses the App.

The Problem: When JSON Narration Falls Short

Plain tool responses work fine for simple queries. But when users want to interact with results — approve something, filter a table, control a deployment — returning {"total": 12, "healthy": 10, "degraded": 2} and having the model narrate it is the wrong interface.

The original MCP mental model was agent-oriented: expose operations, let the model explain results. That breaks down when interaction is inherently visual or requires structured human confirmation.

MCP Apps formula: MCP App = MCP Tool + UI Resource + Host/View protocol

How MCP Apps Work

1

Tool returns data + declares a UI resource

Tool (e.g., get_servers()) returns structured data and declares ui://servers/dashboard in its response metadata.

2

Host detects the metadata, fetches the resource

Host calls resources/read with the declared UI resource identifier.

3

Server returns a bundled frontend app

React, Vue, or plain JS — self-contained in the response. The UI and data are separate.

4

Host renders it in a sandboxed iframe

The app runs isolated from the host page. No regenerating the whole frontend per request.

5

Tool result data passed to running view via postMessage

JSON-RPC over postMessage connects the dynamic data to the static UI resource.

// MCP server: tool that declares a UI resource
const mcpServer = {
  tools: {
    async get_servers() {
      const servers = await db.getServerStatus();

      return {
        // Standard tool result
        content: [{ type: "text", text: JSON.stringify(servers) }],

        // MCP Apps extension: declare the UI resource
        _meta: {
          ui: {
            resource: "ui://servers/dashboard",
            visibility: ["model", "app"]  // accessible by both agent AND UI
          }
        }
      };
    }
  },

  // UI resource: the presentation layer (separate from data)
  resources: {
    "ui://servers/dashboard": {
      mimeType: "text/html",
