The 5 projects

What to build and why each stands out

1. Production RAG Pipeline with Evaluation

Stack: JavaScript/Node.js · Anthropic SDK · Chroma/Pinecone · DeepEval

A RAG pipeline over a real document set (your own notes, a book, API docs) with a full eval harness: retrieval precision, answer faithfulness, hallucination detection. The eval suite is the differentiator — 95% of RAG portfolios don't have one.

  • Chunking strategy (sliding window vs semantic) with benchmarked retrieval quality
  • Re-ranking layer (cross-encoder) that improves top-5 recall by measurable %
  • Hallucination detection running on every response
  • A README with benchmark numbers, not just "it works"

2. Autonomous Coding Agent with CI Integration

Stack: Claude API · Node.js · GitHub Actions · Jest

An agent that accepts a GitHub issue, reads the relevant files, proposes a fix, opens a PR, and passes all tests. The key: it runs in CI on a schedule or on issue label — fully unattended.

  • Tool definitions for file read, file write, test run, and git operations
  • Inspector function: zero failing tests as the exit condition
  • GitHub Actions workflow that triggers the agent on ai-fix label
  • Log of all tool calls + token cost per run stored as a CI artifact

3. Multi-Provider LLM Router with Fallback

Stack: Node.js · Anthropic · OpenAI · Ollama · Express

A gateway API that routes requests to the best available provider based on model capability, cost budget, and latency target. Falls back to a local Ollama model when cloud APIs are unavailable.

  • Provider health checks with automatic failover
  • Cost tracking per request logged to a SQLite DB
  • Model selection algorithm: route classification tasks to Haiku, complex reasoning to Opus
  • Dashboard (even a simple HTML page) showing cost by provider over time

4. AI Agent Memory System

Stack: Node.js · Redis · SQLite · Anthropic API

An agent with three memory types: working memory (current conversation), episodic memory (past interactions stored in DB), and semantic memory (embedded knowledge chunks). Shows you understand why "stateless API calls" break for real assistant use cases.

  • Memory consolidation: compress old working memory into episodic summaries
  • Retrieval: when asked "what did we discuss about X?", search episodic memory by embedding similarity
  • Memory decay: old memories get lower retrieval weight unless recently accessed

5. Real-Time Document Intelligence Dashboard

Stack: React · Node.js · WebSockets · Claude · Chroma

Upload a PDF/document set, ask questions in real time with streaming responses, see exactly which chunks were retrieved and why. The transparency layer — showing retrieval provenance — is what makes this portfolio-grade over a basic chatbot.

  • Streaming responses with Server-Sent Events or WebSocket
  • Citation panel: every answer highlights the source chunks used
  • Confidence indicator: show retrieval similarity scores to the user
  • Export conversation as a structured report (PDF or Markdown)
JavaScript Example

RAG pipeline starter — chunking, embedding, retrieval

JavaScript Example 
import Anthropic from "@anthropic-ai/sdk";
import { ChromaClient } from "chromadb";
import fs from "fs/promises";

const client = new Anthropic();
const chroma = new ChromaClient();

// Sliding window chunker (preserves context at boundaries)
function chunkText(text, chunkSize = 512, overlap = 64) {
  const words = text.split(/\s+/);
  const chunks = [];
  for (let i = 0; i < words.length; i += chunkSize - overlap) {
    const chunk = words.slice(i, i + chunkSize).join(" ");
    if (chunk.length > 50) chunks.push({ text: chunk, startWord: i });
  }
  return chunks;
}

// Embed text using Claude's embedding-compatible model
async function embedTexts(texts) {
  // Using a placeholder — swap for your actual embedding model
  // e.g. OpenAI text-embedding-3-small or a local model
  return texts.map((t) => Array.from({ length: 384 }, () => Math.random())); // stub
}

// Ingest a document into Chroma
async function ingestDocument(filePath, collectionName = "docs") {
  const collection = await chroma.getOrCreateCollection({ name: collectionName });
  const text = await fs.readFile(filePath, "utf8");
  const chunks = chunkText(text);
  const embeddings = await embedTexts(chunks.map((c) => c.text));

  await collection.add({
    ids: chunks.map((_, i) => `${filePath}-chunk-${i}`),
    embeddings,
    documents: chunks.map((c) => c.text),
    metadatas: chunks.map((c) => ({ source: filePath, startWord: c.startWord })),
  });

  return chunks.length;
}

// RAG query: retrieve + generate with provenance
async function ragQuery(question, collectionName = "docs") {
  const collection = await chroma.getCollection({ name: collectionName });
  const [queryEmbedding] = await embedTexts([question]);

  const results = await collection.query({
    queryEmbeddings: [queryEmbedding],
    nResults: 5,
  });

  const context = results.documents[0].join("\n\n---\n\n");
  const sources = results.metadatas[0];

  const response = await client.messages.create({
    model: "claude-opus-4-8",
    max_tokens: 1024,
    system: "Answer questions based only on the provided context. If the answer is not in the context, say so.",
    messages: [
      {
        role: "user",
        content: `Context:\n${context}\n\nQuestion: ${question}`,
      },
    ],
  });

  return {
    answer: response.content[0].text,
    sources, // show these in the UI as citations
    retrievalScores: results.distances[0],
  };
}

// Usage
const chunkCount = await ingestDocument("./my-notes.txt");
console.log(`Ingested ${chunkCount} chunks`);

const { answer, sources } = await ragQuery("What are the main concepts in chapter 3?");
console.log("Answer:", answer);
console.log("Sources:", sources.map((s) => s.source));
